# Seventeen Syllables of Debugging

A make.fun entry for [Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605): a program that writes exactly one haiku about debugging — three lines, 5-7-5 syllables, at most 200 characters — to `/output/entry.txt`.

```
Cursor blinks at three
the logs insist nothing's wrong
yet the build still fails
```

Run it with Node 22: `node main.ts` (honours `MAKEFUN_OUTPUT_DIR`, defaults to `/output`). Deterministic — two runs produce byte-identical output.
